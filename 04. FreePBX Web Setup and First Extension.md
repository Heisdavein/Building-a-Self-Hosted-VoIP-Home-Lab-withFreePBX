# 04. FreePBX Web Setup and First Extension

This guide covers reaching the web interface, creating the first administrator account and creating extension 1001.

## 1. Open the web interface

From the Windows laptop I entered the server’s IP address in the browser:

```
http://192.168.1.149
```

or, depending on the server configuration:

```
https://192.168.1.149
```

A page loading confirms the VM is running, networking works, the server has an address and the web service is up. The address shown is the example from the documented run.

## 2. Self-signed certificate warning

The first page was a browser warning that the connection was not private. This is expected on a fresh install: FreePBX generates a **self-signed certificate**. The connection is still encrypted, but the certificate is not issued by a trusted Certificate Authority, so browsers cannot verify it.

Because the server is only in my home lab and I knew which device I was connecting to, I chose **Advanced**, then **Proceed**. For a server reachable from the internet I would replace the certificate with one from a trusted CA such as Let’s Encrypt.

## 3. Create the administrator account

On a new install no administrator exists, so the setup page asked me to create one: a username, a strong password and an email address. After **Create Account**, FreePBX redirected me to the login page, where I signed in with the new credentials.

This account is separate from the Linux `root` account. Root controls the operating system, while the FreePBX administrator controls the PBX application. Using different credentials for each layer is good practice.

## 5. Open the Extensions module

An extension is a telephone endpoint on the PBX that an IP phone or softphone registers to. Without one a softphone cannot register, no phone can authenticate and no internal calls can be made.

Navigate to **Applications, Extensions**. On a new install the list is empty.

## 6. Add a PJSIP extension

1. Click **+ Add Extension**.
2. Choose **New SIP (Chan_PJSIP) Extension**.

PJSIP is the modern SIP channel driver. Compared with the older `chan_sip` it offers better security features, improved support for current SIP standards, better NAT traversal, more reliable handling of multiple devices and ongoing development. Sangoma recommends it for new installations.

## 7. Extension details

| Field | Value |
| --- | --- |
| User Extension | `1001` |
| Display Name | `My Softphone` |

`1001` follows a simple numbering convention for small offices, for example Reception 1000, My Softphone 1001, Sales 1002, Support 1003. The display name is for people reading the interface. In production it would usually be a person or department name.

FreePBX generated the **SIP secret** automatically: a long random password the SIP client must present to register. I copied it to a secure location for the softphone configuration. A registering device presents the server IP, the extension number and the secret, and the PBX compares them against its database. A match registers the phone and a mismatch rejects it, which stops unauthorised devices impersonating users.

## 8. Leave the other settings at defaults

Voicemail, call recording, advanced SIP settings, caller ID, device options, call waiting, Follow Me, call forwarding and codec preferences were left unchanged. The aim was one working extension. Getting a simple configuration working first means fewer variables when something fails, and extra features can be added later.

## 9. Submit and Apply Config

1. Click **Submit** to save the extension to the FreePBX configuration database.
2. Click the orange **Apply Config** button that appears across the top of the page.

Saving does not activate a change. FreePBX lets an administrator queue several changes and write them into Asterisk’s active configuration at once with **Apply Config**. That groups changes, reloads the PBX once instead of after each edit, lets mistakes be corrected before they affect users and gives control over when changes go live.

After applying, extension 1001 was active and ready to accept SIP registrations.
