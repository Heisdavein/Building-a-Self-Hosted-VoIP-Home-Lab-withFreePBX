Before installing anything I checked that the laptop could run a second operating system reliably. Windows 11 stays running as the host while FreePBX runs as a guest, so both need enough CPU, memory and disk.

## Results

| Component | My system | Status |
| --- | --- | --- |
| Processor | Intel Core i5, 4 physical cores | Suitable |
| Hardware virtualization | Intel VT-x, Enabled | Ready |
| RAM | 8 GB | 2 GB to be allocated to the VM |

## CPU

The processor executes instructions for both the host and the VM. Intel VT-x provides hardware-assisted virtualization. Without it, VirtualBox may refuse to start 64-bit guests or the VM will run much more slowly because CPU instructions are emulated in software. With VT-x enabled the benefits are better performance, faster boot, stability and support for 64-bit guests.

## Memory

RAM assigned to a VM is not shared dynamically while the VM runs. Windows loses access to that portion until the VM shuts down.

- Physical RAM: 8 GB
- Allocated to the VM: 2 GB (2048 MB)
- Left for Windows and other applications: about 6 GB

FreePBX does not need much memory for a lab with a single extension, so extra RAM would add little. Over-allocating can hurt: if Windows runs short of memory it pages to disk, and paging to an SSD is far slower than RAM, which makes the whole machine feel sluggish. Sizing the VM to its workload is usually called right-sizing.

## Storage

A VM’s virtual disk is an ordinary file on the host. Beyond the base install, space is useful for updates, voicemail, logs, call recordings, configuration backups and future packages.

- Host disk: 256 GB SSD
- Virtual disk: 40 GB, **dynamically allocated**

A dynamically allocated disk grows only as data is written. The configured size is 40 GB, while actual usage immediately after creation is around 2 to 3 GB, growing toward the 40 GB limit as FreePBX is installed and used.

## Host operating system

Windows 11 is supported by VirtualBox and works well with Linux guests. In this project it hosts VirtualBox, stores the VM files, provides internet connectivity, and gives me the browser and SSH clients needed to administer the PBX.

## Verifying VT-x is enabled

A CPU can support VT-x while the setting is disabled in BIOS or UEFI, so I checked it directly:

1. Open Task Manager with `Ctrl + Shift + Esc`.
2. Select the **Performance** tab.
3. Select **CPU** in the left-hand list.
4. Find **Virtualization** in the processor information. Mine showed **Enabled**.
